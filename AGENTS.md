# Project Guidelines & Rules

- **DO NOT CREATE OR DESIGN CUSTOM MAPS/LEVELS**: The user explicitly requests that you must **NEVER** design or build custom map structures or custom level layouts for them. If a new boss, level, or world requires level data, always default to the existing pre-defined constants (e.g., `BOSS_LEVEL_DATA`, `DEFAULT_LEVEL_DATA`) in `src/game/constants.ts` completely unmodified, or query existing standard layouts. Do not generate custom map data.
