# Project Guidelines & Rules

- **DO NOT CREATE OR DESIGN CUSTOM MAPS/LEVELS**: The user explicitly requests that you must **NEVER** design or build custom map structures or custom level layouts for them. If a new boss, level, or world requires level data, always default to the existing `boss_level` or `default_level` in `godot/data/levels/official_levels.json` completely unmodified, or query existing standard layouts. Do not generate custom map data.
