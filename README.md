# 史萊姆方塊吞噬者

Godot 4 平台解謎遊戲，目前有十個世界、十場首領戰及關卡編輯器；世界 6～10 新增 45 個正式機關關卡。

支援關卡計時與本機最佳紀錄，方便觀眾比較不同過關走法。計時、暫停、回溯與練習回合規則見 [遊玩說明](godot/README.md#關卡計時與挑戰紀錄)。

使用 Godot 匯入 `godot/project.godot`，按 F5 執行。

操作及測試見 [godot/README.md](godot/README.md)，開發架構見 [ARCHITECTURE.md](godot/docs/ARCHITECTURE.md)。

字型授權：[Noto Sans TC SIL OFL](godot/assets/fonts/OFL.txt)。
