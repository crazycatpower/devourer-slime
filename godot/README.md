# 史萊姆方塊吞噬者

## 執行

使用 Godot 4.7 匯入 `project.godot`，按 F5。亦可從專案根目錄執行 `godot/tools/godot.ps1`。

## 操作

- A / D：左右移動；W：跳躍。
- 滑鼠左鍵：吞噬；右鍵按住瞄準、放開吐出。
- R：重試；Esc：暫停與設定；F11：全螢幕。
- 編輯器：左鍵繪製、右鍵擦除、中鍵拖曳、Ctrl+Z 復原、Ctrl+Y 重做、Ctrl+S 儲存。

## 關卡計時與挑戰紀錄

右上角顯示本次用時與該版關卡的個人最佳。第一次移動、跳躍或吞吐時開始計時，碰到終點立即停止；暫停與失去焦點不計時，子彈時間仍按實際遊玩時間計算。失敗與時光倒流的時間會保留，重新開始整關才歸零。

正常速度的正式遊玩會自動保存最佳成績；測試模式或本回合使用過不同遊戲速度會標示「練習回合」，不更新紀錄。修改版面後使用獨立紀錄，原版成績仍保留。選關畫面顯示最佳時間，過關切換時也會提示本次成績及新紀錄。

分享給觀眾挑戰時，可請對方附上世界、關卡、通關時間及走法；目前紀錄儲存在本機，沒有線上排行榜。

## 目錄

- `src/core`：關卡資料、固定步長物理及首領邏輯。
- `src/render`：方塊、角色、首領及特效繪製。
- `src/ui`、`src/game`、`src/editor`：選單、遊戲及編輯器。
- `data/levels`：Godot 使用的關卡 JSON。
- `tests/unit`、`tests/smoke`：單元、實際輸入路線及遊戲流程測試。
- `tools`：啟動、測試、截圖及關卡資料工具。

## 測試

從專案根目錄執行：

```powershell
godot/tools/test.ps1
godot/tools/test.ps1 unit
godot/tools/test.ps1 -Smoke
```

完整檢查包含腳本與場景編譯、Godot 單元測試與冒煙測試。截圖及冒煙測試使用 `--sandbox` 隔離存檔。

## 關卡與存檔

關卡使用字串陣列 JSON，一個字元代表一格。官方資料位於 `data/levels`；協作規則見根目錄 `AGENTS.md`。

世界展示順序由 `WorldCatalog.ORDER` 決定，內部 slot ID 保持穩定，讓自訂關卡與通關進度持續對應同一關。

世界 6～10 各有九個正式機關關卡，共 45 關，加上五場材質首領。新地圖依使用者後續「做關卡」指示製作，取代先前的標準空房；五場首領仍使用既有 `boss_level`。

新關卡資料位於 `data/levels/mechanism_levels.json`，包含地形、感測器、連線、軌道及每關名稱與提示。`tools/build_mechanism_campaign.py` 可重建這一批資料與 `tests/fixtures/mechanism_solutions.json` 的實際輸入路線，不改動舊世界、首領地圖或設計師匯出。自訂存檔與設計師地圖仍優先於內建版面。

- 世界 6：叫下階梯、回收同一顆砝碼、開地板、回頭找出口、落砂觸發與獨立貨運電路。
- 世界 7：分段冰跳、下坡煞車、冰塔折返、頂棚滑行與反向返回高台。
- 世界 8：砂橋、側挖砂牆、向下掘井、保留砂粒越過刺床、搬砂上台與填補虛空。
- 世界 9：自行發車、貨物作踏腳、下車換乘、下降後跳離、回程卸障、兩件貨物各自填補缺口及三站換乘。
- 世界 10：射擊／吐出引爆、上下層爆破、拆除身後玻璃、攜帶炸藥下樓、爆破登高、冰地板破壞及地下工地。

其中 27 關已重新設計，避免後段只重複開門或原地搭車。保留短入門關，再讓後段交替運用回收、搬運、登高、下掘及換乘；關卡路線也驗證未發車的列車會留站，單靠走路與自動跳障礙無法完成指定機關題。

每關都有選單名稱及遊玩提示；完整路線使用走路、跳躍、吞噬、瞄準及吐出輸入，在子彈時間開啟及關閉兩種設定下驗證通關，同時檢查機關狀態及重試恢復。五場首領使用不同目標：

| 世界 | 首領 | 通關方式 |
| --- | --- | --- |
| 6 感測器 | 感測監督者 | 吐出方塊覆蓋左、上、右三端，維持同時通電 1.5 秒使電路過載；吞回覆蓋物會斷電。 |
| 7 冰 | 冰霜滑行者 | 射擊推動、反向射擊先煞停，下一發才反向推動；依序在三座冷卻站低速停穩一秒。完成一站會取消蓄力招式並增加一秒準備時間。 |
| 8 沙子 | 流砂巨像 | 吞下左下方沙核，躲過加強落砂並帶回左側入口；吐出會把沙核送回首領。 |
| 9 軌道 | 軌道運輸者 | 吞下車頂泥土補給並射擊頭頂感測器發車；每站補回彈藥、重新送信號，隨車走完三段轉彎路線。離車時暫停，1.5 秒後降回地面接回乘客。 |
| 10 TNT | TNT 熔爐 | 吞噬點燃的 TNT，約 0.13 秒拆彈；將取得的 TNT 吐回首領，引爆三次。自己的炸彈與一般 TNT 不會代替回投進度。 |

首領具備進場、招式預告、材質彈藥、目標進度、持續玩法提示、重試及通關銜接。冰站與沙核入口離開鏡頭時顯示方向及距離；冰站顯示進站、煞車及停穩狀態，熔爐炸彈顯示爆炸範圍。站在新首領屋頂時停用地面格子對齊，避免停在邊緣時被拉離。TNT 仍維持 0.4 秒引信；普通射擊不會讓這五場首領共用扣血通關方式。

玻璃世界 Boss（slot 40）的地下填充區在進場及重試時重新抽取泥土位置。每列以約 3% 的比例取整、至少一塊泥土，表層至少兩塊；其餘為玻璃。固定模擬種子可重現場地，向下延伸使用獨立亂數串流，不影響 Boss 攻擊抽樣。

玻璃 Boss 飛行高度為玩家上方 310 世界單位，俯衝最低點深入玩家腳下 80 單位。下砸及俯衝撞泥土時扣一點泥土耐久並暈眩；護盾依血量為 4／8／12。投擲玻璃有水平 ±140、垂直 ±40 單位的瞄準偏差，遇到障礙即碎裂，只打碎直接接觸的玻璃，不爆炸、不貫穿。本體接觸只做固體碰撞與位置分離，不會彈跳或反彈，只有被投擲玻璃直接命中及被本體擠向地形才會致死。

招式意圖隨機抽選：下砸、俯衝、投擲玻璃各佔 30%，護盾修復佔 10%；護盾已滿時不抽修復、沒有可投擲護盾時不抽投擲玻璃，其餘招式按原權重抽選。修復蓄力 1.5 秒，依血量階段補回 2／3／4 面護盾，上限仍為 4／8／12 面。蓄力時顯示修復意圖及可補回數量，命中核心會中斷修復；不修復地形或核心血量。

編輯器新增感測器、拉線、四向軌道、沙子、冰與 TNT 筆刷。感測器為可穿過的獨立層，可與方塊佔據同一格；感測區被實體或飛行方塊覆蓋時持續輸出信號（玩家本身不算方塊）；拉線可覆蓋任何地形，拖曳會自動補成上下左右相接的線路，相交處共用信號。拉線筆刷右鍵只擦線，感測器筆刷右鍵只擦感測器；軌道筆刷右鍵只擦軌道；普通橡皮擦會連地形、感測器、軌道與線一起清除。亮綠色代表通電，線斷開或覆蓋感測器的方塊移走就停止輸出。軌道也是可穿過、可被覆蓋的獨立層。通電時每 0.2 秒把同格方塊沿箭頭搬到下一段軌道，依各段方向轉彎，遇障礙或軌道末端停止；能帶著站在方塊上的玩家一起上下左右移動。R 可旋轉軌道筆刷。沙子與冰被軌道接住時由軌道控制移動。

沙子每 0.1 秒往下落一格並堆積，支撐移除後繼續下落。玩家在冰面上加速、煞車較慢；吐出的普通方塊落到冰面後持續滑動，到牆或冰面結束才停止，吐出的冰塊與被射中的冰塊則在普通地面上也持續滑到障礙。沙子、冰與 TNT 可吞吐並保留材質。吐出 TNT、被射出的方塊命中或收到信號會點燃 0.4 秒引信，倒數時閃爍並顯示倒數圈；吐出的 TNT 撞上地形會留在撞擊位置，沿用剩餘倒數。爆炸會點燃附近 TNT，各自延遲 0.4 秒連鎖引爆，破壞附近可移動方塊及連線，鋼鐵、固定機關與終點保留，近距離玩家會死亡。

舊關卡仍使用原本字串陣列格式；有連線、感測器或軌道的自訂關卡使用 `{ "rows": [...], "wires": [[欄, 列], ...], "sensors": [[欄, 列], ...], "rails": [[欄, 列, 方向方塊ID], ...] }`。儲存、匯入／匯出、複製貼上、復原、重做、縮放地圖尺寸與測試遊玩均保留連線及被方塊覆蓋的感測器、軌道。新方塊文字代碼：`S` 感測器、`R` 右軌道、`L` 左軌道、`U` 上軌道、`D` 下軌道、`A` 沙子、`I` 冰、`T` TNT。

存檔位置為 `%APPDATA%/Godot/app_userdata/Devourer Slime/`：`settings.cfg` 儲存設定、`progress.cfg` 儲存通關紀錄、`levels/slot_NN.json` 儲存自訂關卡。

在遊戲內編輯器儲存的關卡就是官方關卡：`tools/build.ps1` 匯出前會執行 `tools/bake_levels.gd`，把存檔資料夾裡的關卡寫進 `data/levels/designer_levels.json`，該檔案的關卡會取代同一格的內建版面並隨遊戲發佈。

字型依 [SIL OFL](assets/fonts/OFL.txt) 授權。

玩家持有吞下的方塊時會繼承材質能力與顏色：泥土為土褐色，保留 80% 移動速度及略低跳躍；彈力為粉紅色，恢復原本跳躍初速，保留碰撞反彈；沙子為沙黃色，下落時重力提高 60%、軟終端速度提高 40%，上升不受影響；冰為冰藍色，在普通地面也使用低摩擦移動；TNT 為紅色，撞牆、撞天花板或落地時，朝碰撞面的速度達 14 就消耗持有的 TNT，在撞擊位置留下延遲 0.4 秒爆炸的 TNT；一般走路及正常跳落不引爆。爆炸可破壞地形及連鎖引爆，玩家依原有爆炸傷害規則死亡；不提供爆炸抗性。高速移動會沿路檢查撞擊，避免穿過薄牆。左下角顯示當前能力。吐出、消化或重生後能力解除並恢復綠色，不疊加不同材質能力。

軌道筆刷預設依拖曳路徑自動轉向，斜向拖曳會補上下左右相接的格子，閉合路徑保留起點出口；整次拖曳可一次復原。關閉「拖曳軌道自動轉彎」可固定箭頭方向，單格點擊與 R 旋轉仍可手動調整。軌道圖案顯示實際入口與出口的彎道。編輯器新增游標格子座標及重疊機關資訊，使用軌道筆刷 Alt 取材可選到覆蓋方塊下的軌道；貼上預覽顯示連線、感測器與軌道。拖曳每次移動只刷新一次文件，格線僅繪製可見範圍。

機關更新只檢查感測器、沙子及 TNT 所在格子；未改變的信號來源與線路會重用通電結果，移動方塊、切線、爆炸及重試會更新快取。沙子落上感測器觸發 TNT 時，同一次更新立即點燃，0.4 秒後才爆炸。打包關卡保留完整機關圖層，讀取打包資料也支援擴充格式。自動儲存失敗會保留編輯器及未儲存修改，暫停離開或匯入操作；寫入先檢查暫存檔錯誤再替換原存檔。


機關搬運的所有材質現在沿移動間隔連續顯示：軌道 0.2 秒、沙子 0.1 秒、冰面滑行約 0.067 秒。轉彎與連續下落銜接前一段位置，站在方塊上的玩家一起平滑移動，跳離時不瞬間跳到終點；吐出的方塊落格也有短暫銜接動畫。動畫使用模擬時間，所以暫停與子彈時間同步；毀壞或重生會清除動態殘影。格子搬運、感測器與碰撞規則沿用原本判定。

橡皮擦清除同格地形、連線、感測器與軌道，整筆可一次復原；E 可快速切換橡皮擦。筆刷按鈕重複點選仍保留選取亮框，切換工具先結束上一筆拖曳。儲存失敗會顯示「修改仍保留」與「重試儲存」，每筆只嘗試一次自動儲存。匯入失敗以原始位元組還原舊檔。打包資料損壞時停止並保留原檔，正常打包先完整寫入暫存檔，再替換舊檔；未變更資料不重寫。

移動中的冰塊有短滑行光線，沙子帶少量落砂，彈力材質有輕微形變，其他材質保持剛性。粉塵、吞噬與吐出特效跟隨玩家與方塊的顯示位置。重生立即清除前一個角色的顏色及撞擊反應。擦除游標會標示擦除的是全部圖層、連線、感測器或軌道。
