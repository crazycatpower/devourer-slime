# 廢棄生物工廠素材包 v1

使用內建 image_gen 生成。完整提示詞與素材清單見 manifest.json。

五大世界與通用維修區，各含一張背景板及一張九物件透明素材表，共 6 張背景、6 張素材表、54 個裝飾單元。

世界順序為美術主題提案：培養室、材料測試區、回收加工區、能源核心、封鎖出口。此生成素材包已退出世界 1 第 10 關試裝；目前改由 backdrop_layer.gd 程式繪製低對比背景與裝飾。原圖留存供參考。其餘關卡與編輯器保留原背景，未修改關卡布局。

背景是完整構圖，不保證無縫拼接。建議以 cover 方式縮放，配合輕微視差與依遊玩畫面調整的暗色遮罩。背景欄杆與設備皆不可碰撞。

props/ 內為逐件 AtlasTexture 資源，直接引用原始透明 PNG，保留 alpha 且不重複儲存圖片。小物件僅作背景裝飾，建議高度約 16–48 世界單位，關閉碰撞與互動，稀疏放置並降低亮度。不要用裝飾遮住尖刺、落腳邊緣、玩家或瞄準線。

素材皆保留生成原圖；index.html 提供背景與透明小物件總覽，regions.json 記錄各物件區域與透明度檢查。
