## 給錄音與剪輯的操作備註

- 每句錄兩版：一版自然陳述，一版稍有情緒；保留前後乾淨空白，方便避開重要遊戲聲。
- 優先靠移動句子位置與選擇表演版本對畫面，不大幅加速人聲。若句子和關鍵動作重疊，先縮短句子。
- 字幕不必逐字跟讀。主片只放導演腳本指定的短句；需要完整無障礙字幕時，另做完整字幕軌。
- 「還差兩格」「先填滿」「吃掉」必須跟實錄狀態一致，不能為了音樂節奏提前說到尚未發生的結果。
- 沒有旁白也可成立：保留短字幕與完整原音，重新檢查每個規則是否看得懂，再調整停留時間。
