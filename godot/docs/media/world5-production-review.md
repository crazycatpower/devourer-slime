# 第五世界影片製作分析

日期：2026-10-16。依據本專案既有影片抽樣畫面、第三／四世界剪輯腳本，以及第五世界原地圖的正常操作通關路線。

## 先解決的問題

第三世界 `world3-edited-full.mp4`、第四世界 `world4-edited-full.mp4` 的 1、5、12、45 秒畫面已抽樣檢視。兩版在開頭動作之後切入全屏標題卡；第四世界剪輯腳本另有每關章節卡、淡黑轉場及獨立慢動作重播。這些設計有交代資訊，但反覆切斷操作因果。第四世界 `world4-action-cut.mp4` 已把標題疊在動態畫面，方向較適合第五世界。

抽樣可見的另一個問題是整張地圖的留白較大，角色、投擲物、障礙核心和 HUD 在縮小畫面中偏小。觀眾容易看見角色飛過去，卻沒看懂先拿了什麼、射到哪裡、為何能過。以上是對抽樣畫面與腳本的判斷，並非對既有影片每一秒的完整審片，也沒有觀看留存資料。

## 第五世界真正可用的故事

核心題目可以是「這顆史萊姆，靠吃掉地圖過十關」。由容易理解的墊路開始，逐步增加反作用力、材料回收、窄通道與 Boss 的壓力。

| 關卡 | 實錄路線的重點 | 剪輯應讓觀眾理解的事 |
| --- | --- | --- |
| 1 | 用泥土建立落點，再取第二塊推進 | 方塊同時是材料與移動工具 |
| 2 | 分次搭建安全落點 | 下一步要落在哪裡 |
| 3、4 | 原關卡的連續移動與通過 | 動作方向、入口與出口的關係 |
| 5 | 先放置彈跳落點，再取材料前進 | 預先準備如何改變後面的跳躍 |
| 6 | 填出牆面落點、保留回收材料，最後反衝跳躍 | 為何必須多搬一塊材料 |
| 7 | 較長路線的連續操作 | 避免觀眾在來回移動中失去方向 |
| 8 | 迷宮中保留材料，依序處理出口障礙及支撐 | 先處理什麼、最後一塊為何不能浪費 |
| 9 | 彈跳與穿牆口之後的跨越 | 起跳前的安排與落地結果 |
| 10 | 原 Boss 場地中的取物、閃避、攻擊與通關 | 攻擊有沒有命中、局勢有沒有推進 |

第八關與 Boss 是本批原速素材的主要長段。第八關適合做「資源規劃」的小故事；Boss 適合用階段性成果建立結尾，避免相似閃避與搬運無差別重複。

## 高完成度成片需要的工作

1. **主題與開場。** 先用 5～8 秒展示一次最清楚的反衝跨越或第八關最後穿出障礙，再用一句話交代目標。標題疊在動作上，不另插長片頭。這是剪輯方案，並非流量預測。
2. **完整證據與精華分開交付。** 保留十關原速實錄作底稿；另製作約 3～4 分鐘的主片。搬運和等待可以剪短或標示加速，關鍵起跳、命中、死亡風險與落地維持可讀的速度。
3. **導引視線。** 投擲前短暫標示目標格，落點出現時讓標示立即消失。特寫必須同時保住角色、發射方向和落點；鏡頭不能只追角色而裁掉原因。
4. **字幕與旁白。** 每個難點只說一個訊息，例如「最後這塊，不能拿來跳」。術語首次出現時用畫面說明。字體以手機實際觀看尺寸驗收，不靠桌面全屏判斷。
5. **聲音。** 保留吞、吐、碰撞、彈跳與勝利聲作為節奏依據；配樂隨段落推進，重要命中前可降低音樂。旁白、音效、音樂需分軌混音，再測試手機與耳機播放。
6. **畫質。** 目前底稿為 1280×720、60 FPS。正式高解析度成片應用相同已驗證輸入重新錄製原生 1080p 或更高解析度，再檢查 HUD 與鏡頭；單純放大 720p 不會增加原生細節。
7. **包裝。** 封面只呈現一個可理解的衝突，例如角色、兩列障礙與出口。標題與封面承諾的場面要在影片中清楚兌現。橫版主片與直式短片應各自構圖，避免直接裁切重要機關。
8. **驗收。** 原速底稿逐關核對通關、幀數、聲音與原地圖；剪輯版再檢查動作因果、字幕遮擋、切點、音量、手機可讀性，以及音樂與素材的使用權。

所需職能是導演／剪輯、遊戲操作與擷取、動態圖像與字幕、聲音後製、封面設計及品質檢查；可以由少數人兼任，但每項都需要實際驗收。「百萬級」若指觀看數，現有資料不足以估算；若指製作質感，上述項目可以作為具體製作與驗收標準。

## 本次實錄方式

使用既有遊戲模擬搜尋正常移動、跳躍、吞吐輸入，再由實際 GameScreen 以相同輸入錄製影音。不是人工手持操作。關卡、物理、角色位置和勝利狀態沒有為了通關而改寫；地形變動均由遊戲內吞吐規則產生。Boss 使用原生成規則與固定種子 7，讓路線與錄影可重現。

完整素材、操作資料、來源地圖雜湊與驗證報告位於 `godot/build/recordings/world5/`；此資料夾受 Git 忽略。這份分析與新增錄影工具仍為本機工作，尚未提交或推送 GitHub。


## 原版美術動畫版

成片輸出為 `build/recordings/world5/world5-animated-cut.mp4`，沿用三分鐘剪輯的十關實錄與音軌。片頭、片尾改用遊戲自身 `SlimeFace`、`TilePainter` 繪製器匯出的透明 PNG；包含原版方形史萊姆、眨眼、擠壓表情、持有材料狀態、泥土材質與出口的 16 幀動畫。片頭背景取自第八關實錄，沒有另外設計關卡。

角色動畫使用匯出美術做位移、縮放、擠壓拉伸與吞吐編排；它是片頭演出，不冒充關卡操作。正片的反衝軌跡與命中特效取自相同正常輸入的模擬記錄。保留流體轉場、動態字幕、結尾慶祝與補充音效。原版地圖及遊戲程式均未為此改動。

素材來源記錄：`build/recordings/world5/original-art/manifest.json`。製作程式：`export_original_art.gd`、`animate_film.py`；驗收程式：`verify_animation.py`。以上製作中間檔位於受 Git 忽略的 build 目錄。成片仍為 720p60，沒有配音。
