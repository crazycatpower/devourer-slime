# 第五世界｜導演與剪輯執行腳本 v1

**片名提案：〈路不夠？把它吃出來。〉**  
**形式：** 約 3 分鐘、16:9、60 fps、十關精華敘事。短句旁白搭配少量重點字幕，遊戲聲音主導動作節奏。  
**主題：** 一塊方塊，從落腳點、推進器，變成穿過迷宮與擊破 Boss 的工具。  
**情緒線：** 好奇 → 看懂規則 → 驚喜 → 材料危機 → 最後一口的釋放。

這是一份針對現有實錄的創作方案，不是對某位創作者工作方式的轉述。已檢視既有影片抽樣與第五世界關鍵畫面，並用已驗證輸入重播標記取得材料、投擲、Boss 填格及擊破時間。下列「成片時間」為粗剪目標，尚未完成逐幀鎖定；「來源時間」均為單關 AVI 的局部秒數。事件標記來自模擬輸入幀，套入影片時須逐幀對齊，預留至少前後 0.5 秒素材。

## 一、頂級完成度應該體現在哪裡

### 1. 觀眾的眼睛先到，特效才出現

每次精彩動作都要建立三件事：角色在哪裡、要過什麼、準備用什麼方法。投擲前給目標格一次細框，投擲後沿真實方向帶視線，最後把落地結果留清楚。觀眾已經理解的時候，不再補滿畫面的箭頭與文字。

先做一版完全沒有特效、只靠剪接與原音就能看懂的主片，再增加特效。若刪掉特效便看不懂動作，應先補鏡頭或調整剪接。

### 2. 「絲滑」來自接點的連續

四種連續至少保住一項：**運動方向、主體位置、圖形形狀、聲音節奏**。例如上一鏡角色向右起跳，下一鏡同樣向右移動，角色落在相近的畫面區域；前一鏡的吐塊聲還未結束，下一鏡已接住它的節拍。

大多數關卡用動作中硬切。真正有辨識度的轉場集中在三處：開頭切入、第八關突破、第九關進 Boss。全片不以反覆淡黑、長片頭或每關相同的模板動畫分段。

### 3. 鏡頭留住因果

放大必須同時看得到角色、投擲物與重要落點。一般關卡讓全景交代空間，再短暫靠近；第八關可另做出口局部特寫，先用全景上的細框說明特寫位置。不要在關鍵飛行中追得太緊，讓落點跑出畫面。

現有來源為 720p，先以 720p 做粗剪，數位推近通常控制在約 1.08～1.18 倍。需要明顯特寫時使用資訊插窗，或在正式製作前重新錄製較高原生解析度；不能把放大後的模糊當成質感。

### 4. 快慢要有理由

取材、等待和重複走位可以濃縮。接近障礙、投擲、命中、落地時回到原速。全片僅選兩個動作使用明顯慢動作：第六關最後反衝、第八關最後穿出。Boss 結尾保留原速，讓連續吞噬本身形成節奏。

### 5. 音效替切點搭橋

吞、吐、彈跳與命中是主拍。轉場只在確實有跨鏡運動時加入短促掠過聲；微推鏡、字幕入場不必每次都響。重要動作前降低配樂，讓原本的遊戲聲突然變得清楚，往往比增加一層爆炸聲更有力量。

### 四種輔助特效

- **目標提示：** 細框隨目標格定位，約 0.4～0.7 秒；一次只指一件事。投擲前出現，命中後離開。
- **材料提示：** 取得材料後給角色持有物一圈短描邊，與 UI 遊戲物件保持分離。第八關「最後一塊」可停約 0.8 秒。
- **命中強調：** 低透明局部亮度脈衝，2～4 幀，落在真正的命中點。全片不持續套 RGB 分離或全屏白閃。
- **時間濃縮：** 長搬運以動作剪接為主；需要連續加速時，1×→3×或4×的過渡約 8～12 幀，並標示加速。投擲前至少恢復原速約 0.3 秒。高倍率素材的音訊重新處理，不讓遊戲聲尖銳失真。

60 fps 來源做 0.5 倍慢動作時，可在 60 fps 時序中規律重複來源幀，先確保方塊邊緣完整。不要直接對整段套光流補幀；若另試補幀，逐幀檢查方塊、投擲物、細線與 HUD 有沒有扭曲。

## 四、聲音與畫面風格

### 聲音編排

採用有清楚段落變化的電子節奏：前半輕巧、迷宮段降低鼓密度、Boss 段增加低頻與壓力。音樂剪點服從遊戲動作，不把畫面硬塞進所有拍點。

分四條音訊軌：遊戲原音、補強效果、旁白、配樂。保留吞吐聲的識別性；補強音只能增加重量，不應把普通填格做成 Boss 爆炸。旁白出現時先從音樂讓出空間，再處理相互遮蔽的頻段。投擲前的「安靜」是降低配樂，原本的環境與操作聲仍然存在。

實錄合併影片的 volumedetect 平均音量約 -32.9 dB；這不是整合 LUFS，不能直接當作平台響度結論。正式混音另量測整合響度、峰值與動態，並在手機喇叭及耳機上檢查旁白清晰度。

### 字幕與色彩

遊戲的紫色障礙是主色，提示以暖金色或偏白呈現，危險才使用紅色。主字幕通常每次 6～12 個中文字、最多兩行；長句交給旁白，不讓觀眾一邊讀文章一邊追高速角色。

以 1080p 版面設計時，重點字幕可先用約 48～60 px 測試，再依實際字型與手機預覽調整。一般字幕、關卡角標、片名三種層級即可。字幕避開底部重要落點；上下安全位置按每鏡選擇，不機械固定在同一條遮住角色。

## 六、交給剪輯者的交付與驗收

**先交粗剪：** 三分鐘時間線、旁白試讀、原音與臨時音樂。先檢查第六關的開場伏筆有沒有兌現，第八關三次材料用途是否清楚，Boss「填滿→吞噬→擊破→出口」是否成立。

**再交效果版：** 加入上述三個主要段落轉場及少量提示。每個效果都能說明它在引導哪個動作；無法說明的效果先移除。主片若超過三分鐘，優先縮搬運與重複閃避，不削掉首次規則說明和最後結果。

**最終驗收：**

1. 十關都出現，而且各自有可辨識的操作與結果。
2. 每次重排或時間省略仍保住材料取得、使用和通過的因果。
3. 不虛構實錄中不存在的死亡、瀕死、命中、額外材料或關卡機制。
4. 不把精華版標成全程未剪原速；完整原速版另行保留。
5. 用手機尺寸看一次：目標、字幕和角色是否能同時辨識。
6. 關閉音樂看一次、只聽聲音聽一次；前者檢查畫面敘事，後者檢查節奏與聲音切點。
7. 慢動作、遮罩、轉場與字幕逐幀檢查穿幫；輸出後完整檢查影音同步和首尾。

**這一版的設計重點：讓觀眾先看懂一塊方塊的用途，再逐步看見它能解決多困難的局面。轉場把這條故事接順，特效只在需要觀眾注意的地方出手。**
