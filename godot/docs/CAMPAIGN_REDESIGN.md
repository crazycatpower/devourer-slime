# 全關卡優化

**目前狀態：依使用者後續要求，第一、第二、第三世界已完整恢復成全關卡優化前的官方配置（1–30 關），並移除新增名稱與提示。生成器只輸出第四、第五世界的覆寫與操作解答，重新生成也不會再次改動前三世界。以下全世界調整敘述為先前方案紀錄。**

本次依使用者「重新優化所有關卡」的明確要求重新整理官方關卡。五個世界共 50 個位置已全部有實際內容：46 個一般關卡，以及保留戰鬥配置的四個 Boss。第五世界第十關是綜合終章，沒有新增第五個 Boss。

## 設計與難度

| 世界 | 調整 |
| --- | --- |
| 1 | 地面起步、低階跳躍、吞吃門、短刺區，再介紹接近跳躍頂點的向下吐出借力。移除早期過大的高度差。 |
| 2 | 彈性平台逐步變高與增加段數，平台下方有安全地面。原本 60 列的重複長井改為能重新嘗試的短段落。 |
| 3 | 玻璃一層一份材料，先單門、再連續晶門、再搭配高台與短刺區；移除後段巨大垂直材料壓力。 |
| 4 | 保留先前已驗證的九關教學路線，在後段補給區增加備用方塊。虛空填塊再吞會消化，提示遵循這個規則。 |
| 5 | 補齊十關。組合破玻璃、填虛空、跳刺區、彈性轉場與吐出登高；終章高台上再加入晶門與短刺區。 |

普通跳躍高度約 150 像素。普通階梯用可抵達的高度差；借力平台高 200 像素，需要在跳躍後段向下吐出。刺區前後保留起跳、落地與重新觀察的位置。所有關卡都有名稱與提示，選關名稱提高文字對比，進關提示顯示 14 秒。第 50 關按一般關卡呈現。

## 資料與相容性

`data/levels/official_levels.json` 為原始匯出檔，未改寫。`data/levels/campaign_levels.json` 是最終官方一般關卡的覆寫資料，由 `tools/build_campaign.mjs` 生成；生成器先更新第四世界資料，再合併整個旅程。可用 Node 執行生成器同步更新關卡與操作解答。

自訂儲存關卡仍照原有機制覆蓋官方關卡，沒有更動玩家自訂地圖或清除玩家紀錄。Boss 的第 10、20、30、40 關地形與戰鬥程式保留，加入教學提示。

## 驗證

- 46 個一般關卡各在子彈時間開／關設定下，用 `SimInput` 路線到達終點；不修改地形、不傳送玩家。
- 驗證全部一般關卡有效且互異；50 個位置無空白占位且有提示。
- 127 項單元測試，7121 次檢查通過，包含既有 Boss 回歸測試。
- 66 次真實視窗與鍵鼠事件 smoke 檢查通過；第一關會實際跳過新版低階。
- 原本依賴某個官方地形的底層 codec／物理測試改讀原始匯出 fixture，讓測試本身不隨關卡設計改動失效。
- 117 個腳本編譯通過。capture 工具 `--campaign` 產生第五世界選關，以及第一、二、三、四、五世界代表關卡的起點與中段實際畫面。

目前以 Godot 原生模擬、關卡路線與冒煙測試驗證。

通關路線是可解性證據，尚不能代替玩家對難度與趣味的實際回饋。後續可依玩家失敗位置微調平台間距與補給數量。
