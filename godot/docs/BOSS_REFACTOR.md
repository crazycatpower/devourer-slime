# Boss 流程修復

維持四個既有 Boss 的玩法與官方關卡，重寫故障集中的流程。

| 流程 | 修復與不變條件 |
| --- | --- |
| 第四世界吞噬 | 中斷後只退到最後一個已吞掉方塊的進度；消失的格子在吞噬期間不再造成死亡，完成後產生終點。 |
| 第三世界護盾 | 新生護盾立即設定公轉座標；入場期間也跟隨本體，不在世界原點等待下一 tick。 |
| 第二世界碰撞 | 依移動方向選最近的實心列，只損傷該列實際接觸的行；零水平速度不觸發側向反彈。預覽共用同一查詢。 |
| 第二世界速度 | 水平上限 18、垂直上限 28 世界單位/tick，阻止反覆彈性碰撞無限加速。 |
| 第一、四世界場外恢復 | 保留身體格子與戰鬥進度，短入場返回，玩家保持控制；同步前後座標以免畫面跨場景插值。第二世界仍保留掉出場景扣耐久的既有玩法。 |
| 彈跳接觸 | 上、側、下方接觸都解除 grounded，清除前一次射擊反作用力。 |
| 危險提示 | 第一世界只在實際致命跳躍狀態長刺；重組顯示實際判定目的格，已吃掉的格子不再繪製；第四世界危險核心採用碰撞常數；第三世界即將發射時顯示正確提示。 |

`tests/unit/test_boss_regressions.gd` 以官方 10、20、30、40 關重現中斷、同 tick 護盾碰撞、方向接觸與場外恢復；不建立新地圖。

模擬變更由 Godot 首領回歸測試驗證。繪圖只讀取模擬狀態。
